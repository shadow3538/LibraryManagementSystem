# library management system

A SQL Server based library management system created for database design and T-SQL practice.

## features

- member management
- author management
- category management
- publisher management
- book management
- book copy management
- book issue and return
- fine calculation and payment
- book reservation
- librarian management
- damaged and lost book tracking
- audit logging
- views
- stored procedures
- triggers
- functions
- indexes
- advanced T-SQL queries

## technologies

- Microsoft SQL Server
- T-SQL

## database files

### library_management_DDL.sql

Contains the database structure and programmable database objects, including:

- database and schema
- tables
- primary keys and foreign keys
- constraints
- indexes
- views
- stored procedures
- triggers
- functions

### library_management_DML.sql

Contains sample data and T-SQL practice queries, including:

- insert, update and delete
- joins
- subqueries
- correlated subqueries
- derived tables
- exists and not exists
- aggregate functions
- group by and having
- case, iif and coalesce
- string and date functions
- offset and fetch
- cte
- window functions
- running totals
- procedure and function testing

## purpose

This project is intended for learning and practicing SQL Server database design, T-SQL, database objects and advanced queries.

## note

This repository contains a learning/practice database project and is not intended as a production-ready library management application.
